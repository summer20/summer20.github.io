## 背景与目标

为陈慧莹（应用统计硕士在读、27届毕业生，数据分析/风险分析方向）设计并实现一个高端、现代、具科技感的个人品牌官网，用于秋招求职时给招聘方留下深刻印象。风格参考 Apple / OpenAI / Linear / Vercel / Stripe / Notion，核心诉求是"用数据解决问题，用 AI 提升效率，把创意变成真正可落地的产品"。

本轮目标是先做出**可在本地浏览器直接打开预览**的完整静态站点；是否/何时部署上线由用户后续决定，站点结构本身不因此而妥协（纯静态文件，随时可部署）。

## 技术架构

**纯 HTML / CSS / 原生 JavaScript，零第三方依赖，零构建步骤。**

理由：用户在多个技术方案（A. 纯 HTML/CSS/JS；B. React+Vite+Tailwind+Framer Motion；C. Next.js）中明确选择了 A，即使 B 被作为推荐方案提出。已确认按 A 执行。

**关键约束**：站点必须能通过双击 `index.html` 直接在浏览器打开使用（`file://` 协议），不依赖本地服务器。因此：
- 不使用 `fetch()` 读取本地 JSON/数据文件（`file://` 下会被浏览器 CORS 拦截）
- 不使用 `<script type="module">` 做 ES module 导入（同样在 `file://` 下会被部分浏览器拦截）
- 所有文案/内容数据以 JS 对象字面量形式写在普通 `<script>`（非 module）中

**目录结构**：

```
~/portfolio/                          ← 独立 git 仓库（已 git init）
  index.html                          ← 唯一页面，单页滚动 + 锚点导航
  css/
    tokens.css                        ← CSS 变量：深/浅色两套配色、间距、圆角
    style.css                         ← 布局、组件样式、动效
  js/
    main.js                           ← 导航高亮、主题切换、语言切换触发、
                                         滚动进入动画（IntersectionObserver）、
                                         移动端菜单、数字滚动计数器
    i18n.js                           ← CONTENT_ZH / CONTENT_EN 字典 + 切换逻辑
    visualizations.js                 ← 雷达图、环形进度条（纯 SVG + JS，无图表库）
  assets/
    images/                           ← 头像/项目/生活照占位图（几何风格占位，非破损图标）
    resume/陈慧莹_数据分析简历.pdf      ← "下载简历"按钮对应文件
  docs/superpowers/specs/             ← 本设计文档所在目录
```

**数据流**：所有可变内容（导航文案、Hero 文案、About 信息、技能数值、经历列表、项目列表、成果数字、Gallery 主题、联系方式）集中定义在 `i18n.js` 的 `CONTENT_ZH` / `CONTENT_EN` 两个对象中，`main.js` 在页面加载和语言切换时读取当前语言对象、把文本写入带 `data-i18n-key` 标记的 DOM 节点。主题（深/浅色）通过给 `<html>` 元素设置 `data-theme="dark"|"light"` 属性驱动 `tokens.css` 里的 CSS 变量切换，用户的语言/主题选择存 `localStorage`，下次打开记住偏好（默认：浅色 + 中文）。

**错误处理 / 兼容性**：
- 图片占位一律用内联 SVG 或 CSS 渐变块实现，不引用可能 404 的外部图片文件，避免"图裂"状态
- JS 被禁用时，静态 HTML 内容（文字、结构）仍可读，只是失去动效/切换能力（渐进增强思路）
- 动效整体尊重 `prefers-reduced-motion: reduce`，命中时关闭滚动进入动画、数字滚动、雷达图描边动画，直接展示最终状态

**测试 / 验证方式**：这是纯前端静态展示站点，无业务逻辑、无数据持久化，不引入自动化测试框架。验证方式为人工检查清单：
1. 双击 `index.html` 直接打开，确认无控制台报错、无因 `file://` 协议导致的功能失效
2. 深色/浅色切换、中/英文切换均正常且刷新后记住上次选择
3. 桌面宽屏、平板、手机三种视口下布局无错位、无横向滚动
4. 各板块滚动进入动画、卡片 hover、雷达图/环形进度/数字滚动动效均正常触发
5. 系统开启"减少动态效果"时，动效自动降级但内容仍完整可读

## 视觉系统

**配色方案：Electric Ink**（浅色默认，深色可切换，用户已在可视化脑暴工具中确认）

| 用途 | 浅色模式 | 深色模式 |
|---|---|---|
| 背景 | `#f5fbfc` | `#0a0f14` |
| 卡片/表面 | `#ffffff` | `#10161c` |
| 正文文字 | `#0a0f14` | `#f2f6f7` |
| 主渐变（青→紫） | `#0891a8 → #5b3df0` | `#18c8d9 → #7c5cff` |
| 强调色（橙，按钮描边/徽章） | `#c5661f` | `#ff8a3d` |
| 边框 | `rgba(0,0,0,.08)` | `rgba(255,255,255,.12)` |

**字体**：系统字体栈 `-apple-system, "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif`。不引入外部字体文件，理由：离线可用、中英文覆盖俱佳、无 FOUT/联网加载问题。大标题字重 800、字距收紧（`letter-spacing: -0.02em`）；正文 400/500。

**圆角与留白**：卡片圆角 20–24px；8pt 间距系统；大量留白，避免拥挤。

**动效原则**：
- Hover：卡片上浮 + 阴影加深，200–300ms ease
- 滚动进入：`IntersectionObserver` 驱动淡入 + 上移，Bento 卡片群错峰（stagger）出现
- 雷达图 / 环形进度条：滚动到可视区域时才触发描边动画
- 数字滚动：Achievements 数字进入视口后从 0 滚动到目标值，只触发一次

## 双语机制

`i18n.js` 中维护 `CONTENT_ZH` 与 `CONTENT_EN` 两个结构一致的对象（导航、Hero、About、Skills、Experience、Projects、Achievements、Gallery、Contact 各一份文案）。导航栏语言切换按钮触发 `main.js` 中的渲染函数，遍历所有 `[data-i18n-key]` 节点，用当前语言对象对应字段替换文本内容；专业术语（Python/SQL 等）中英文版本保持原词不译。切换结果存入 `localStorage`，刷新后保持。

## 明确不做的事（v1 范围边界）

- 不做后端、数据库、任何服务端逻辑——纯静态站点
- 不做真实部署上线——本轮目标是本地可预览；后续若要上线，静态文件可直接搬到任意托管平台，无需重写代码
- 不生成虚构的生活照片、项目截图、微信二维码图片——全部使用占位设计，图片文件由用户后续提供替换
- Achievements 数字、项目描述、Experience 内容全部锚定用户提供的简历原文和本轮对话中确认的真实信息，不编造未确认的数据
- 不做多页路由、博客系统、评论区、后台管理界面
- Featured Projects 第 4 项（个人网站/简历工具）本轮只做卡片结构和占位图，不编造项目截图或过度具体的功能描述
